# Bot commands

| Command | What it does |
|---------|--------------|
| `/start` | main menu |
| `/help` | help |
| `/health` | system status |
| `/stats` | panel statistics |
| `/bandwidth` | traffic statistics |
| `/config` | settings without a restart |
| `/user <username\|id>` | user card |
| `/node <uuid>` | node card |
| `/host <uuid>` | host card |

Everything else is available through menu buttons: users, nodes, hosts, subscription templates, snippets, panel API tokens, billing, violations, blocked addresses.

Commands only work for Telegram IDs listed in `ADMINS`. See [Telegram bot](/en/guide/bot).
