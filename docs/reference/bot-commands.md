# Команды бота

| Команда | Что делает |
|---------|-----------|
| `/start` | главное меню |
| `/help` | справка |
| `/health` | состояние системы |
| `/stats` | статистика панели |
| `/bandwidth` | статистика трафика |
| `/config` | настройки без перезапуска |
| `/user <username\|id>` | карточка пользователя |
| `/node <uuid>` | карточка ноды |
| `/host <uuid>` | карточка хоста |

Всё остальное доступно кнопками из меню: пользователи, ноды, хосты, шаблоны подписок, сниппеты, API-токены панели, биллинг, нарушения, заблокированные адреса.

Команды выполняются только для тех, чей Telegram ID перечислен в `ADMINS`. Подробнее — [Telegram-бот](/guide/bot).
