# Настройки панели

Почти всё в панели настраивается из интерфейса, без правки файлов и перезапуска: **Настройки**. Изменение применяется сразу.

Значение берётся по цепочке **база данных → `.env` → значение по умолчанию**. Пока настройку не трогали в интерфейсе, работает то, что задано в `.env` или зашито в код; после первого изменения она живёт в базе, и `.env` на неё больше не влияет.

В списке настройки помечены: `В БД` — значение переопределено и хранится в базе, `.env` — взято из окружения, `По умолч.` — из кода. Отдельные значения только для чтения: они управляются со своих страниц, а здесь показаны для полноты.

::: tip Эта страница собрана из кода
Названия, описания и значения по умолчанию берутся прямо из каталога настроек панели, поэтому не расходятся с тем, что вы видите в интерфейсе. Обновляется командой `python scripts/gen_settings_docs.py`.
:::

| **📡 Collector: лимит запросов** | `collector_rate_limit` | `1/second` | Rate limit для эндпоинта сбора метрик от нод-агентов (формат: '1/second'). |


### 💾 Кэш

| Настройка | Ключ | По умолчанию | Что делает |
|---|---|---|---|
| **💾 Кэш: максимум записей** | `cache_max_entries` | `5000` | Максимальное количество записей в in-memory кэше. При превышении используется LRU-вытеснение. |
| **⏱️ Кэш: TTL по умолчанию (сек)** | `cache_default_ttl` | `300` | Время жизни записей в кэше по умолчанию. Меньше = актуальнее данные, но больше запросов к БД. |


### 🔍 Конвейер проверки нарушений

| Настройка | Ключ | По умолчанию | Что делает |
|---|---|---|---|
| **⏱️ Очередь нарушений: интервал обработки (сек)** | `violation_drain_interval` | `3.0` | Как часто worker забирает порцию пользователей из очереди. Меньше = быстрее реакция, но выше нагрузка. |
| **📦 Очередь нарушений: размер порции** | `violation_chunk_size` | `200` | Сколько пользователей обрабатывать за один цикл. Больше = быстрее разгребается очередь, но пиковая нагрузка выше. |
| **🔀 Макс. фоновых задач** | `violation_max_background_tasks` | `20` | Максимальное количество одновременных фоновых задач (торренты и пр.). При превышении новые задачи отбрасываются. |
