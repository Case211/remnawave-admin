# Документация Remnawave Admin

Здесь лежат исходники сайта документации: **https://case211.github.io/remnawave-admin/**

Русская версия — в корне этого каталога, английская — в `en/`. Сайт собирается VitePress и публикуется автоматически при пуше в `main`.

## Локальный запуск

```bash
cd docs
npm install
npm run dev      # http://localhost:5173/remnawave-admin/
npm run build    # сборка в .vitepress/dist
```

## Что где

| Каталог | Что внутри |
|---------|-----------|
| `guide/`, `en/guide/` | руководство: установка, настройка, возможности, эксплуатация |
| `reference/`, `en/reference/` | справочник: переменные, API v3, вебхуки |
| `grafana/` | пять дашбордов Grafana для импорта |
| `fail2ban/` | готовые правила fail2ban |
| `audits/` | рабочие разборы безопасности и нарушений, на сайт не публикуются |
