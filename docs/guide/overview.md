# Что это такое

Remnawave Admin — надстройка над панелью [Remnawave](https://remna.st): веб-интерфейс и Telegram-бот, которые берут на себя всё, чем панель не занимается. Своя база, свой сбор данных с нод, свои правила и уведомления.

Панель Remnawave остаётся источником правды по пользователям и конфигурации — Remnawave Admin ходит в неё по API, а всё, что накапливает сам (подключения, нарушения, метрики, письма, аудит), держит в собственном PostgreSQL.

## Из чего состоит

| Часть | Что делает | Где живёт |
|-------|-----------|-----------|
| **Telegram-бот** | Управление пользователями, нодами и хостами прямо из чата, уведомления с кнопками действий | контейнер `bot` |
| **Веб-панель** | Интерфейс администратора: аналитика, нарушения, терминал, почта, плагины | контейнеры `web-backend` и `web-frontend` |
| **Коллектор** | Фоновая обработка данных с нод, детект нарушений, синхронизация с панелью | тот же образ, режим коллектора |
| **Node Agent** | Читает логи Xray и метрики хоста на каждой ноде, выполняет команды | отдельный контейнер на ноде |

Всё, кроме агента, поднимается одним `docker compose up -d`.

## Что умеет

### Управление

- Пользователи: поиск, создание, редактирование, устройства HWID, массовые операции
- Ноды: включение и перезапуск, трафик, метрики хоста, удалённый терминал и каталог скриптов
- Хосты, шаблоны подписок, сниппеты, API-токены панели
- Аудит-лог: полная история действий администраторов

### Анти-абуз

Семь анализаторов ищут разделение подписки: временной, географический, по ASN, по профилю поведения, по устройствам, по HWID и по User-Agent. Пороги настраиваются, действия автоматические — от предупреждения до жёсткой блокировки. Подробности в разделе [Анти-абуз](/guide/anti-abuse).

Отдельно живёт [детект торрентов](/guide/torrents): тег роутинга Xray и разбор трафика через nDPI.

### Наблюдаемость

- Дашборд с трендами онлайна, нарушений и очереди коллектора
- Гео-карта подключений с детализацией по городам
- Аналитика: топ пользователей, трафик по нодам, минутная грануляция за сутки
- [Метрики Prometheus](/guide/monitoring) и пять готовых дашбордов Grafana

### Коммуникации

- Уведомления в Telegram с маршрутизацией по топикам, push в мобильное приложение, email и webhook
- [Встроенный почтовый сервер](/guide/mail): прямая MX-доставка, DKIM, приём входящих
- Мобильное приложение для Android с виджетом и push

### Расширения

- [Магазин плагинов](/guide/plugins) прямо в панели
- [Внешний API](/reference/api) с ключами и правами доступа
- [Исходящие webhook](/reference/webhooks) с HMAC-подписью

## Что нужно, чтобы начать

Панель Remnawave с доступом к API, сервер с Docker и Telegram-бот. Всё остальное — по желанию: агент на нодах нужен только для анти-абуза, почтовый сервер и мониторинг включаются отдельно.

Дальше: [требования к серверу](/guide/requirements) и [установка](/guide/installation).
